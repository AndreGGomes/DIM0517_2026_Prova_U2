
# Orientações para a prova

1. Faça o fork desse repositório e compartilhe-o com o usuário gibeonufrn

2. A prova contém 4 questões, independentes. Altere obrigatoriamente os arquivos indicados no enunciado de cada questão e opcionalmente, crie ou altere outros arquivos que julgar necessário.

3. Tenha a atenção para realizar os commits e push apenas no intervalo da prova. Não serão aceitos, commits realizados posteriormente.



# API Disponibilizada

API simples com dois endpoints, implementada em 4 linguagens:


| Endpoint       | Resposta                         |
|----------------|----------------------------------|
| `GET /hello`   | `{"message":"Hello, World!"}`    |
| `GET /healthy` | `{"status":"healthy"}`           |
